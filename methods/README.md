# Methods

[Collection](../README.md) · [Learn](../learn/README.md) · [Topics](../topics/README.md) · [Resources](../resources/README.md) · [Community](../community/README.md)

Methods pages help you choose and assess an approach for a scientific question. They complement the [topic guides](../topics/README.md), which organize questions by neuroscience subject, and the [resource library](../resources/README.md), which holds the catalog entries.

## Choose an approach

Reusable mathematical approaches cross tasks and data types. Choose one because it addresses a part of your question; a project may combine several.

| Approach | What it helps examine | One resource entrance |
| --- | --- | --- |
| Dynamical systems | Trajectories, stability, oscillations, and state transitions. | [Dynamical Systems in Neuroscience](../resources/books.md#dynamical-systems-in-neuroscience-the-geometry-of-excitability-and-bursting). |
| Probability and statistical inference | Uncertainty, noise, latent causes, and predictions from observations. | [Statistical Thinking](../resources/books.md#statistical-thinking-for-the-21st-century), then [Probabilistic Machine Learning](../resources/books.md#probabilistic-machine-learning-advanced-topics) for deeper inference. |
| Information theory | What neural responses convey about a specified stimulus, task, or variable. | [Information Theory and Neural Coding](../resources/papers-and-reviews.md#information-theory-and-neural-coding). |
| Control theory | Feedback, state estimation, delays, and action in a changing body or environment. | [Computational Motor Control](../resources/courses-and-lectures.md#computational-motor-control-reza-shadmehr). |
| Optimization | Constrained objectives, fitting, and learning procedures. | [Mathematics for Machine Learning](../resources/books.md#mathematics-for-machine-learning), connected to [fitting and comparison](fitting-and-model-comparison.md). |

Task workflows answer a different question: what sequence of choices makes a concrete model, simulation, data analysis, or comparison defensible? Use the pages below for those sequences. A workflow may use one or several mathematical approaches.

| Your task | Guide |
| --- | --- |
| Formulate and derive a theoretical account | [Theory and model building](theory-and-model-building.md) |
| Implement a model and explore its behavior | [Simulation](simulation.md) |
| Turn recordings into interpretable measurements | [Neural data analysis](neural-data-analysis.md) |
| Estimate parameters or compare explanations | [Fitting and model comparison](fitting-and-model-comparison.md) |
| Infer parameters when likelihoods are impractical | [Simulation-based inference](simulation-based-inference.md) |
| Design an intervention or reason about a causal effect | [Causal inference and experimental design](causal-inference-and-experimental-design.md) |
| Make results reproducible and reusable | [Reproducible research](reproducible-research.md) |

## Find a scientific setting

The same method can mean different things across systems. Locate the question in [neurons and dendrites](../topics/neurons-and-dendrites.md), [circuits and dynamics](../topics/circuits-and-dynamics.md), [coding and representations](../topics/coding-and-representations.md), [learning and plasticity](../topics/learning-and-plasticity.md), [inference and prediction](../topics/inference-and-prediction.md), [perception and decision](../topics/perception-and-decision.md), [memory and navigation](../topics/memory-and-navigation.md), [action and control](../topics/action-and-control.md), or [NeuroAI](../topics/neuroai.md).

For background, use [learning paths](../learn/README.md). For selected books, tutorials, papers, software, datasets, and standards, use the [resource library](../resources/README.md).

For structure and growth, see [connectomics](../topics/connectomics.md) and [development](../topics/development-and-self-organization.md). For individual variation or device implementation, see [computational psychiatry](../topics/computational-psychiatry.md) and [neuromorphic computing](../topics/neuromorphic-computing.md).
