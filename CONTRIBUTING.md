# Contributing

Thanks for helping curate this collection of computational neuroscience resources. Please open an issue for discussion or submit a pull request with focused changes.

## Adding a resource

- Add resources that are useful for computational neuroscience research, education, or reproducible practice.
- Prefer the resource's official page or repository. Use a direct link that does not require an account when one is available.
- Check that the link works and points to the intended resource. Include a short, factual description so readers can tell why it belongs.
- Place the entry in the most relevant section and follow its existing order. Keep foundational papers in chronological order.
- Use this format: `- [Resource name](https://example.org) - Short description.` End each entry with a period.
- Explain access requirements where they matter: distinguish a free online text from a publisher listing, and mention accounts or agreements for data downloads.
- For software, check that the project has usable documentation and is not archived or deprecated. Classic books and papers are assessed for their educational value instead of recent updates.
- Avoid duplicate entries, promotional language, and unsupported claims. Mention a license only when you have verified it.

Write descriptions in your own words. Contributions to this list are offered under the repository's CC0 license; linked resources retain their own licenses.

## Pull requests

Keep each pull request focused. Explain what changed and why, and include the resource's official URL. The Markdown formatting and link checks run automatically; please resolve failures before requesting review. For a broken link report, include the affected URL and the relevant resource entry.
